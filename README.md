# UiPath Ticket Booking Automation

## 📌 Project Overview
This project automates a web-based ticket booking process using UiPath Studio. 
The bot performs login, ticket search, passenger detail entry, booking confirmation,
and extracts booking details into Excel automatically.

## 🚀 Features
- Automated web login and navigation
- Dynamic ticket search and selection
- Passenger details automation
- Booking confirmation handling
- Data extraction to Excel
- Exception handling and logging
- Improved workflow organisation

## 🛠 Tools & Technologies
- UiPath Studio (Modern Design Experience)
- Web Automation
- Excel Automation
- Selectors & UI Explorer

## ▶️ How to Run
1. Open project in UiPath Studio
2. Configure input Excel file
3. Run Main.xaml

## 📂 Project Structure
- **Main.xaml** – Controls overall workflow
- **Login.xaml** – Handles login process
- **SearchTickets.xaml** – Searches tickets based on input
- **PassengerDetails.xaml** – Enters passenger data
- **Confirmation.xaml** – Captures booking details

## 📊 Input & Output
- Input: `InputData.xlsx`
- Output: `OutputData.xlsx`
